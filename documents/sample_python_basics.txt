Python is a high-level, interpreted programming language created by Guido van Rossum
and first released in 1991. It emphasizes code readability with its use of significant
indentation.

Key Features of Python:
- Simple and readable syntax
- Dynamic typing (no need to declare variable types)
- Interpreted (no compilation step like Java)
- Large standard library ("batteries included")
- Support for multiple programming paradigms (OOP, functional, procedural)

Python vs Java Comparison:
1. Type System: Python uses dynamic typing while Java uses static typing
2. Syntax: Python uses indentation; Java uses curly braces
3. Compilation: Python is interpreted; Java compiles to bytecode
4. Memory: Python has automatic garbage collection (like Java)
5. Inheritance: Python supports multiple inheritance; Java uses interfaces

Common Python Data Structures:
- list: Like Java's ArrayList. Example: [1, 2, 3]
- dict: Like Java's HashMap. Example: {"key": "value"}
- tuple: Immutable list. Example: (1, 2, 3)
- set: Like Java's HashSet. Example: {1, 2, 3}

Virtual Environments:
Python uses virtual environments to isolate project dependencies.
This is similar to how Maven/Gradle manages dependencies per project.
Command: python -m venv .venv

Package Management:
- pip: Python's package manager (like Maven Central)
- pyproject.toml: Like pom.xml or build.gradle
- requirements.txt: Lists all dependencies with versions

Popular Python Frameworks:
- FastAPI: Modern web framework (like Spring Boot)
- Django: Full-featured web framework
- Flask: Lightweight web framework
- pytest: Testing framework (like JUnit)

Async Programming in Python:
Python supports async/await syntax for concurrent programming.
This is similar to Java's CompletableFuture but built into the language.
Example:
    async def fetch_data():
        result = await some_async_operation()
        return result

Error Handling:
Python uses try/except instead of Java's try/catch:
    try:
        risky_operation()
    except ValueError as e:
        handle_error(e)
    finally:
        cleanup()
